# Menu images

Drop one image per menu item here, named after the item's id:

| Menu item | File |
|---|---|
| Toadstool cupcakes | `toadstool-cupcakes.webp` |
| Fairy Treats | `fairy-treats.webp` |
| Rainbow fruit wands | `rainbow-fruit-wands.webp` |
| Garden veggie cups | `garden-veggie-cups.webp` |
| Honey pinwheel sandwiches | `honey-pinwheel-sandwiches.webp` |
| Petal pink lemonade | `petal-pink-lemonade.webp` |
| The cake | `fairy-cake.webp` |

- `.webp`, `.jpg` and `.png` are all picked up; `.webp` is preferred.
- Export around 1600 px on the long side, 4:5 portrait, under ~250 KB.
- Missing images show a soft illustrated placeholder automatically.
- Alt text lives in `menuImageAlt` in `src/data/menuImages.js`.
