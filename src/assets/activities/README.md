# Activity images

Drop one image per activity here, named after the activity's id:

| Activity | File |
|---|---|
| Flower Crown Studio | `flower-crown-studio.webp` |
| Fairy Treasure Hunt | `fairy-treasure-hunt.webp` |
| Toadstool Cupcake Bar | `toadstool-cupcake-bar.webp` |
| Fairy Potion Lab | `fairy-potion-lab.webp` |
| Freeze, Fairy! | `freeze-fairy.webp` |
| Bug & Bloom Safari | `bug-bloom-safari.webp` |
| Wish Jars | `wish-jars.webp` |
| Musical Toadstools | `musical-toadstools.webp` |
| Fairy Storytime | `fairy-storytime.webp` |

Any activity in any theme works the same way: the id is the activity
name in lowercase with spaces as hyphens and punctuation removed.

- `.webp`, `.jpg` and `.png` are all picked up; `.webp` is preferred.
- Export around 1600 px on the long side, 4:5 or 4:3, under ~250 KB.
- Missing images show a soft illustrated placeholder automatically.
- Alt text comes from `activityImageAlt` in `src/data/activityImages.js`.
